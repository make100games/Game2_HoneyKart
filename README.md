This is the source code for the game Honey Kart. You can [play the game for free in the browser here](https://make100games.itch.io/honey-kart).

The game uses Unity's karting microgame as a foundation and builds on it. On top of the microkarting template I added:
* a custom terrain
* cartoony shaders
* custom characters
* trained AI opponents
* items that allow you to launch bombs
* music
* sound effects
* a basic menu system
* a coin-based boost mechanic

The game was developed in Unity version 6000.1.13f1
